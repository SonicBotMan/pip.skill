# 🛡️ PIP

**被通知"PIP"了？绩效明明正常却被优化？先把这个看完。**

---

## 简单说

这是一个**开源的劳动维权方法论 GitHub 仓库**，分享给网友使用的 AI Agent Skill。

---

## 发生了什么事

你应该见过这类场景：

> 早上到公司，HR 把你叫进小会议室，说"公司调整，你的岗位没了"。 "补偿金会考虑的，先签这个吧。"

大多数人：
- 不知道公司其实违法了
- 不知道该要多少钱
- 被压着当场签字
- 签完才后悔

**但其实——劳动仲裁没有你想的那么难，赔偿金也没有你想的那么少。**

---

## 这个 Skill 能帮你做什么

- **定性判断**：公司说的理由是否合法，是否违法解除
- **证据缺口分析**：缺什么证据、怎么补充
- **谈判筹码评估**：你手里有什么牌、怎么用
- **分步行动计划**：现在做什么、下一步做什么、每一步的法律依据
- **输入结构化**：标准化的信息收集，确保不遗漏
- **实战案例库**：18 个真实/社区案例，"对号入座"快速定位
- **谈判话术库**：6 大类话术，精准怼回 HR

---

## 维权方法论总纲

```
第一步：定性 — 这是什么性质的解除？
↓
第二步：查据 — 公司能证明自己的理由吗？
↓
第三步：算账 — 我实际能拿到多少？
↓
第四步：谈判 — 我用什么姿势进场？
↓
第五步：行动 — 什么时候仲裁、怎么仲裁？
```

## 扩展资源

本 Skill 配备两个强大的实战工具：

### 实战案例库
- **18 个真实/社区案例**，覆盖最常见的维权场景
- 分类清晰：绩效相关 / 程序违规 / 证据博弈 / 经济性裁员 / 合同到期 / 特殊情形
- 每个案例包含：情况描述 → 定性分析 → 赔账结果 → 仲裁结果 → 关键证据 → 启示与教训

### 谈判话术库
- **6 大类话术**，针对 HR 不同态度和话术精准怼回
- 证据博弈：索要绩效考核表、质疑培训/调岗真实性
- 程序违规：质疑通知时效、工会通知、解除证明
- 威胁应对：应对"不签字就停社保/工资"的非法威胁
- 协商策略：锚定 2N 赔偿、设置时间边界
- 拖延应对：设置谈判时限，避免公司恶意拖延

## 使用指南

### 方式一：阅读 SKILL.md
- 直接阅读 `/SKILL.md` 文件，获取完整的维权方法论
- 适合：深入理解五步框架、法律依据、计算公式

### 方式二：参考实战案例库
- 阅读 `/case-library.md`，找到和你情况最相似的案例
- 适合：快速定位、学习成功经验、避免常见坑

### 方式三：使用谈判话术库
- 阅读 `/negotiation-script-library.md`，找到针对性的 HR 话术回怼
- 适合：HR 找你谈话时、谈判过程中

### 方式四：在兼容平台中使用
- **OpenClaw / ClawHub**：部分平台支持直接从 GitHub 安装 Skill
  ```bash
  openclaw skill add https://github.com/SonicBotMan/pip.skill
  ```
- **Hermes Agent**：如果平台支持加载外部 Skill，可以尝试
- **其他工具**：复制内容到你使用的 AI 助手中

## 输入结构建议

当你使用这个 Skill 时，建议按以下结构提供你的情况：

```
【基本情况】
- 在职年限：X 年 X 个月
- 月均工资：约 X 元（含奖金/补贴/津贴）
- 合同类型：固定期限 / 无固定期限
- 是否签过竞业限制协议：是 / 否
- 年假是否休完：是 / 否 / 不清楚

【解除情况】
- 公司说的理由是什么？（原话）
- 公司是否给了书面通知？
- HR 态度如何？（协商 / 强制 / 有威胁）
- 你被要求签什么文件？

【我的证据】
- 绩效记录：有 / 无
- 培训记录：有 / 无
- 工资流水：有 / 无（覆盖几个月）
- 社保记录：有 / 无
- 考勤记录：有 / 无
- 录音 / 照片：有 / 无

【我的疑问】
- 不清楚的地方（例如：赔偿计算方式、仲裁流程等）
```

## 适用情况

- [ ] HR 突然叫你去谈话，说你不用来了
- [ ] 绩效评分正常，却收到了 PIP
- [ ] 公司让你签"协商解除协议"或"离职申请"
- [ ] 被强制调岗、降薪、撤门禁
- [ ] 合同到期了公司说不续
- [ ] 被威胁"背调会说坏话"

---

## 三个最重要的原则

> **不要当场签字。** 说"我需要看一下"然后离开，这不会让你少拿钱。

> **不要告诉公司你有哪些证据。** 先听公司说什么，再决定亮什么牌。

> **拖时间对你有利。** 公司比你更想尽快解决。
