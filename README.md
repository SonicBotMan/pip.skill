# 🛡️ PIP

**被通知"PIP"了？绩效明明正常却被优化？先把这个看完。**

---

## 简单说

这是一个 **AI Agent Skill**。

你只需要告诉它你的情况——比如"老板突然让我第二天不用来了"，它会告诉你：**你该怎么做、该要多少钱、什么字不能签**。

不需要你懂法律。

---

## 发生了什么事

你应该见过这类场景：

> 早上到公司，HR 把你叫进小会议室，说"公司调整，你的岗位没了"。 "补偿金会考虑的，先签这个吧。"

大多数人：
- 不知道公司其实违法了
- 不知道该要多少钱
- 被压着当场签字
- 签完才后悔

**但其实——劳动仲裁没有你想的那么难，赔偿金也没有你想的那么少。**

---

## 这个 Skill 能帮你做什么

- **定性判断**：公司说的理由是否合法，是否违法解除
- **证据缺口分析**：缺什么证据、怎么补充
- **谈判筹码评估**：你手里有什么牌、怎么用
- **分步行动计划**：现在做什么、下一步做什么、每一步的法律依据
- **输入结构化**：标准化的信息收集，确保不遗漏

## 维权方法论总纲

```
第一步：定性 — 这是什么性质的解除？
↓
第二步：查据 — 公司能证明自己的理由吗？
↓
第三步：算账 — 我实际能拿到多少？
↓
第四步：谈判 — 我用什么姿势进场？
↓
第五步：行动 — 什么时候仲裁、怎么仲裁？
```

---

### 第一步：定性

#### 方法：给公司的解除理由做"归类检验"

任何解除劳动合同，要么合法，要么违法。公司说自己合法，必须过以下三重检验：

#### 检验 A：理由是否属于法定理由？

《劳动合同法》规定公司能单方面解除的合法理由只有三类：

| 类型 | 具体理由 | 典型话术 | 后果 |
|------|---------|---------|------|
| 第39条（员工过错） | 严重违纪、试用期不合格、刑事责任等 | "你严重违反公司制度" | 程序合规 = 可能合法 |
| 第40条（员工无过错） | 不胜任工作、医疗期满、客观情况重大变化 | "你不能胜任这个岗位" | 程序合规 + 满足条件 = 可能合法 |
| 第41条（经济性裁员） | 产重整、生产困难、技术革新等 | "公司要组织优化/裁员" | 程序合规 + 满足条件 = 可能合法 |

**判断逻辑：**
```
IF 公司说的理由 NOT IN {39条, 40条, 41条} THEN
    → 几乎可以确定违法解除
    → 跳到"第四步：谈判"
ELSE
    → 继续检验 B 和 C
```

#### 检验 B：程序是否合规？

即使理由合法，程序也必须合规，否则仍是违法解除：

| 程序要求 | 检查方法 | 不满足的后果 |
|---------|---------|-------------|
| 提前 30 天书面通知 OR 支付 1 个月代通知金 | 有没有书面通知，时间是否够了 | 增加赔偿 |
| 通知工会（如果有工会） | 直接问公司 HR，"工会有没有收到通知" | 增加赔偿 |
| 出具解除/终止劳动合同证明书 | 离职时必须给，不给可投诉 | 增加赔偿 |
| 办理社保减员和档案转移 | 离职后 15 日内必须办理 | 增加赔偿 |

**任何一步没做到 → 增加赔偿。**

#### 检验 C：绩效"没问题"在法律上的意义

> 这是关键点：很多公司拿"绩效不达标"说事，但法律上很难证明"不能胜任"。

**关键逻辑：**
```
IF 公司用第 40 条（不能胜任）解除 THEN
    → 公司必须证明三件事：
        1. 有客观考核标准且员工知道（你签过字）
        2. 经过培训或调岗（给你调岗/培训过）
        3. 调岗/培训后仍不能胜任（有新的考核结果）
    
    IF 公司拿不出以上三份证据 THEN
        → 举证责任在公司，"不能胜任"这条理由站不住
        → 违法解除，2N 赔偿
    
    ELSE IF 公司有充分证据 THEN
        → 程序合规 + 事实清楚 = 合法解除
        → 此时谈 N+1 赔偿
```

**结论：绩效评估记录是核心证据，必须立即固定。**

### 第二步：查据——公司能证明自己的理由吗？

#### 方法：反向举证——公司必须拿出什么？

劳动纠纷中，**举证责任在公司，不在员工**。公司说你违纪、不能胜任，公司必须拿出证据。

#### 常见解除理由 & 公司必须证明的东西

| 公司说的理由 | 公司必须证明什么 | 拿不出来怎么办 |
|------------|--------------|-------------|
| "你严重违反制度" | ①制度曾向你公示（你签过字）；②制度内容合法合理；③违规行为达到"严重"程度 | 程序违法，2N 赔偿 |
| "你不能胜任" | ①考核标准你签过字；②给你调岗或培训过；③调岗/培训后仍不胜任 | 程序违法，2N 赔偿 |
| "客观情况重大变化" | ①确实发生了客观情况变化；②变化达到"重大"程度；③无法继续履行合同 | 程序违法，2N 赔偿 |
| "经济性裁员" | ①满足裁员条件（经营困难/技术革新等）；②向劳动部门报告过；③优先留用了长约员工 | 程序违法，2N 赔偿 |
| "合同到期不续签" | 公司主动不续 → 必须支付 N 赔偿金 | 不支付 → 违法，2N |

**实操建议：**
- 第一步到第三步：定性、查据、算账 —— 这些在公司找你谈话之前就要准备好
- 第四步：谈判 —— 用这三步的结论去谈，而不是凭感觉

### 第三步：算账——我实际能拿到多少？

#### 方法：三层赔偿金计算

```
实际能拿到的 = max(协商结果, 仲裁结果)
             = min(你的理想值, 公司的承受上限)
```

#### 第一层：保底数字（依法肯定能拿到的）

| 形式 | 计算方式 | 依据 |
|------|---------|------|
| 违法解除 | 2N 赔偿金 | 《劳动合同法》第 87 条 |
| 合法解除（无过错） | N 或 N+1 | 《劳动合同法》第 40 条、第 46 条 |
| 协商解除 | N+1 | 《劳动合同法》第 36 条 |

**N = 在职年限 × 月均工资**
- 在职年限：6 个月以上算 1 年，不满 6 个月算 0.5 年
- 月均工资：解除前 12 个月平均工资（含奖金/补贴/津贴）

**上限：** 超过当地平均工资 3 倍的，基数按 3 倍算，年限最高 12 年

#### 第二层：附加可追讨项目（很多人忘记要）

| 项目 | 法律依据 | 说明 |
|------|---------|------|
| 未支付的工资/奖金/报销 | 第 30 条 | 解除前的欠款 |
| 未休年假折算工资 | 《职工带薪年休假条例》 | 未休按 300% 折算 |
| 加班费 | 第 44 条 | 工作日加班 150%，周末 200% |
| 未签劳动合同的双倍工资 | 第 82 条 | 入职超 1 个月未签，第 2 个月起双倍工资，最多 11 个月 |
| 未签无固定期限合同的双倍工资 | 第 82 条 | 连续签两次后有权要求签无固定期限，公司拒绝则双倍 |
| 竞业限制补偿金 | 法解释一第 38 条 | 如果签过竞业限制协议，离职后按月支付，不支付 2 个月可解除 |

#### 第三层：特殊情形的额外筹码

| 形式 | 可主张 | 法律依据 |
|------|-------|---------|
| 公司说"合同到期不续签" | N 赔偿金（公司主动不续） | 第 46 条第 5 项 |
| 公司 2 个月不支付竞业限制补偿金 | 书面通知解除竞业限制义务 | 法解释一第 38 条 |
| 签了低于法定 80% 的解除协议 | 向仲裁委申请撤销协议 | 法解释一第 35 条 |
| 被"事实劳动关系"（合同到期继续工作但没签新合同） | 如果公司终止，最多要 N 赔偿金 | 法解释一第 34 条 |

### 第四步：谈判——用什么姿势进场？

#### 方法：谈判桌上的四张牌

#### 第一张牌：法律牌（最强的牌）
- "根据《劳动合同法》第 87 条，违法解除是 2N 赔偿金"
- 亮出这张牌时，同步说出数字——"2N 是 X 元，这是法律规定的"
- 适用场景：公司自知理亏，愿意谈
- 权衡：先亮数字可能降低赔偿意愿，但建立底线

#### 第二张牌：证据牌（底牌，不要轻易亮）
- "我这里有完整的绩效考核记录、工资流水、社保记录"
- 适用场景：公司在虚构解除理由时，让对方知道你不是好欺负的
- 注意：不要提前告诉对方你有哪些证据，让对方先亮理由

#### 第三张牌：程序牌（针对公司程序漏洞）
- "你们提前 30 天通知了吗？工会收到通知了吗？"
- 适用场景：公司理由合法但程序不合法，可增加赔偿
- 权衡：提程序问题可能激化矛盾，但能争取更多补偿

#### 第四张牌：时间牌（拖得起的人占优）
- 劳动仲裁 1 年时效，从知道权利被侵害之日起算
- 权衡：拖时间 = 公司要花更多精力应诉 = 公司更愿意谈
- 适用场景：公司想尽快了结，你反而可以要价更高

---

### 第五步：行动——什么时候仲裁、怎么仲裁？

#### 仲裁真的不难
- 材料交上去等通知就行，不需要律师（虽然建议请）
- 时效 1 年，你有足够时间准备
- 费用相对低（仲裁费、复印费）

#### 什么时候仲裁
- **优先谈判**：仲裁是最后手段，先谈
- **谈判破裂信号**：公司拒绝任何赔偿或给远低于法定的赔偿
- **公司恶意信号**：强行逼签、不给出具证明、拖欠工资等

#### 仲裁流程（简化）
1. 准备材料：解除通知书、工资流水、社保记录、考勤记录、劳动合同
2. 去劳动仲裁委：通常是公司所在地或劳动合同履行地的仲裁委
3. 填申请表：写明仲裁请求（2N 赔偿金、未付工资、未休年假等）
4. 等开庭：通常 30-60 天通知，简易程序 1 次开庭
5. 调解：开庭前有调解环节，可以达成和解
6. 裁决：调解不成的，仲裁委出具裁决书

## 补充：纠纷预警——识别公司经营困境的信号

> 以下内容来自少数派 SSPAI 亲身仲裁经历 + JD331 裁员应对

**关键洞察：** 大多数劳动纠纷，在公司找你谈话之前就已经埋下了伏笔。**越早判断，越能主动。**

### 公司陷入困境的常见预警信号

- 无缘无故消失的公务用车
- 越来越差的节日福利、下午茶
- 工资发放越来越迟
- 中高层员工集中离职
- 员工工作量异常增加（单人承担多人工作）
- 老板/高管开始频繁"消失"或情绪异常
- 公司开始严查考勤、报销（准备裁员前兆）

**实操：** 在决定入职前或在职期间，定期查一查公司是否有大量合同纠纷、欠款诉讼。这些信号出现后，就要开始**暗中收集证据**，做好最坏打算。

## 使用指南

### 什么时候用这个 Skill
- ✅ HR 找你谈话，说"绩效不达标"或"公司调整"
- ✅ 合同到期不续签，公司不给任何补偿
- ✅ 被要求签"自愿离职"、"双方无争议"等协议
- ✅ 怀疑公司违法解除劳动合同
- ✅ 准备仲裁或谈判，需要计算赔偿

### 这个 Skill 能帮你做什么
1. **帮你定性**：判断解除是否违法，违法程度如何
2. **帮你算账**：计算你应该拿多少赔偿，包括被遗忘的项目
3. **教你谈判**：用什么姿势进场，什么时候亮什么牌
4. **告诉你下一步**：现在收集什么证据，什么时候仲裁、怎么仲裁

### 这个 Skill 不能替代什么
- ❌ 不能替代专业律师
- ❌ 不能替代仲裁庭审
- ❌ 不能保证一定拿到多少赔偿（但能告诉你法定标准）
- ❌ 不能帮你和公司谈判（只能给策略建议）

## 输入结构建议（标准化的信息收集）

当你使用这个 Skill 时，建议按以下结构提供你的情况：

```
【基本情况】
- 在职年限：X 年 X 个月
- 月均工资：约 X 元（含奖金/补贴/津贴）
- 合同类型：固定期限 / 无固定期限
- 是否签过竞业限制协议：是 / 否
- 年假是否休完：是 / 否 / 不清楚

【解除情况】
- 公司说的理由是什么？（原话）
- 公司是否给了书面通知？
- HR 态度如何？（协商 / 强制 / 有威胁）
- 你被要求签什么文件？

【我的证据】
- 考核记录：有 / 无
- 培训记录：有 / 无
- 工资流水：有 / 无（覆盖几个月）
- 社保记录：有 / 无
- 考勤记录：有 / 无
- 录音 / 照片：有 / 无

【我的疑问】
- 不清楚的地方（例如：赔偿计算方式、仲裁流程等）
```
