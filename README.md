# 🛡️ PIP

**被通知"PIP"了？绩效明明正常却被优化？先把这个看完。**

---

## 简单说

这是一个 **AI Agent Skill**。

你只需要告诉它你的情况——比如"老板突然让我第二天不用来了"，它会告诉你：**你该怎么做、该要多少钱、什么字不能签**。

不需要你懂法律。

---

## 发生了什么事

你应该见过这类场景：

> 早上到公司，HR 把你叫进小会议室，说"公司调整，你的岗位没了"。 "补偿金会考虑的，先签这个吧。"

大多数人：
- 不知道公司其实违法了
- 不知道该要多少钱
- 被压着当场签字
- 签完才后悔

**但其实——劳动仲裁没有你想的那么难，赔偿金也没有你想的那么少。**

---

## 这个 Skill 能帮你做什么

- **定性判断**：公司说的理由是否合法，是否违法解除
- **证据缺口分析**：缺什么证据、怎么补充
- **谈判筹码评估**：你手里有什么牌、怎么用
- **分步行动计划**：现在做什么、下一步做什么、每一步的法律依据
- **输入结构化**：标准化的信息收集，确保不遗漏
- **实战案例库**：18 个真实/社区案例，"对号入座"快速定位
- **谈判话术库**：6 大类话术，针对 HR 常见话术精准怼回

---

## 维权方法论总纲

```
第一步：定性 — 这是什么性质的解除？
↓
第二步：查据 — 公司能证明自己的理由吗？
↓
第三步：算账 — 我实际能拿到多少？
↓
第四步：谈判 — 我用什么姿势进场？
↓
第五步：行动 — 什么时候仲裁、怎么仲裁？
```

---

## 案例库与话术库

本 Skill 配备两个强大的实战工具：

### 实战案例库
- **18 个真实/社区案例**，覆盖最常见的维权场景
- 分类清晰：绩效相关 / 程序违规 / 证据博弈 / 经济性裁员 / 合同到期 / 特殊情形
- 每个案例包含：情况描述 → 定性分析 → 赔账结果 → 仲裁结果 → 关键证据 → 启示与教训
- 快速定位："我的情况像案例 X"，直接参考其成功经验

### 谈判话术库
- **6 大类话术**，针对 HR 不同态度和话术精准怼回
- 证据博弈：索要绩效考核表、质疑培训真实性
- 程序违规：质疑通知时效、工会通知、解除证明
- 威胁应对：应对"不签字就停社保"、拖延战术
- 协商策略：锚定 2N、设置时间边界
- 每个话术包含：适用场景、怼话正文、权衡分析、常见反驳及应对

## 完整使用流程

```
1. 描述你的情况
   ↓
2. Skill 自动加载实战案例库和话术库
   ↓
3. 匹配相似案例，快速了解类似情况的处理方式
   ↓
4. 根据公司话术，从话术库中选择精准怼回
   ↓
5. 五步框架：定性 → 查据 → 算账 → 谈判 → 行动
   ↓
6. 输出结构化行动计划
```

## 适用情况

- [ ] HR 突然叫你去谈话，说你不用来了

## 使用方法

在 AI Agent 里，直接粘贴下面这段，然后改成你自己的情况：

```
我昨天被 HR 叫去谈话，说我绩效不达标。
我的绩效评分最近一年都是 A/B。
公司让我签一份协议，说会给我补偿金。
我该怎么办？
```

Agent 会自动加载本 Skill 的案例库和话术库，帮你分析并提供具体的怼话和行动建议。

---

## 三个最重要的原则

> **不要当场签字。** 说"我需要看一下"然后离开，这不会让你少拿钱。

> **不要告诉公司你有哪些证据。** 先听公司说什么，再决定亮什么牌。

> **拖时间对你有利。** 公司比你更想尽快解决。

---

## 免责声明

本 Skill 提供的是基于公开法律条文的通用信息整理，不构成律师函法律意见。复杂案件建议咨询专业劳动法律师。各地仲裁标准有差异，具体策略需要结合当地情况调整。
