# 🛡️ 劳动维权助手

**被辞退？绩效正常却被说"不达标"？公司让你签的文件看不懂？**

这不是你的错。但你需要知道：**你不是一个人，法律站在你这边。**

---

## 困境

一位程序员，在某知名电商公司工作了3年，绩效评分一直良好以上。某天，HR 突然约谈，说"业务调整，你的岗位没有了"。

他问："有书面通知吗？"
HR 说："先签这个协商解除协议，补偿金会给你的一部分。"

他签了。

半年后，他才知道——**他绩效正常，根本不能以"不能胜任"为由解除。** 公司没有证明他不能胜任的客观考核标准，也没有经过培训或调岗。这根本就是**违法解除**。

按照《劳动合同法》第87条，违法解除是 **2N 赔偿金**。他本可以拿到 6 个月工资。但他签了那份协议，只拿到了 1 个月。

**他不是个例。**

---

## 为什么受害者往往选择沉默？

- 不知道公司违法了
- 不知道怎么计算自己应得的金额
- 怕仲裁耗时耗力、影响下一份工作
- HR 态度强势，现场施压让你当场做决定
- 签了文件后，后悔也来不及了

**劳动纠纷中，举证责任在公司，不在你。** 但前提是——你要知道怎么用这条规则。

## 这个 Skill 能做什么

这不是一份法律条文汇编。这是一套**经过实战检验的维权决策方法论**，帮你从"完全无助"到"心里有数"。

### 五步走

```
第一步：定性  — 公司说的理由，法律上站得住脚吗？
第二步：查据  — 公司能证明自己的主张吗？
第三步：算账  — 我实际能拿到多少钱？
第四步：谈判  — 我怎么进场谈，才能不吃亏？
第五步：行动  — 什么时候仲裁？怎么准备材料？
```

## 适用场景

- 被公司单方面解除，合同未到期
- 绩效正常，却被说"不能胜任"
- 公司让你签协商解除协议/离职申请
- 被变相裁员（调岗、撤门禁、无薪长假）
- 拖欠工资、加班费、年终奖
- 合同到期公司不续签
- 被威胁背调/被要求签竞业限制

## 核心原则

> **不要签任何你不理解的文件。**

> **不要在谈判中暴露你的底牌和证据。**

> **拖时间对你有利，公司的举证责任在公司，不在你。**
