# 🛡️ PIP

**你的 P（绩效）其实是 O（优化）**

---

## 这是什么

一个 AI Agent Skill，帮你从"突然被叫去谈话"到"心里有数"。

不是法律咨询，是**经过实战验证的维权方法论**——五步走，绩效正常却被"优化"的时候能救命。

---

## 困境

一位程序员，在某知名电商公司工作了3年，绩效评分一直良好以上。某天，HR 突然约谈，说"业务调整，你的岗位没有了"。

他问："有书面通知吗？"
HR 说："先签这个协商解除协议，补偿金会给你的一部分。"

他签了。

半年后，他才知道——**他绩效正常，根本不能以"不能胜任"为由解除。** 公司没有证明他不能胜任的客观考核标准，也没有经过培训或调岗。这根本就是违法解除。

按照《劳动合同法》第87条，违法解除是 **2N 赔偿金**。他本可以拿到 6 个月工资。但他签了那份协议，只拿到了 1 个月。

**他不是个例。**

---

## 你不是一个人

- 不知道公司其实违法了
- 不知道怎么算自己该拿多少钱
- HR 态度强势，现场压你当场做决定
- 签了文件才后悔

**劳动纠纷里，举证责任在公司，不在你。** 但前提是——你要知道怎么用这条规则。

---

## 五步走

```
第一步：定性  — 公司说的理由，法律上站得住脚吗？
第二步：查据  — 公司能证明自己的主张吗？
第三步：算账  — 我实际能拿到多少钱？
第四步：谈判  — 我怎么进场谈，才能不吃亏？
第五步：行动  — 什么时候仲裁？怎么准备材料？
```

## 适用场景

- 被 PIP 了（Performance Improvement Plan，江湖俗称"裁员预审"）
- 绩效正常，却被说"不能胜任"
- 公司让你签协商解除协议
- 被变相裁员（调岗、撤门禁、无薪长假）
- 合同到期公司不续签
- 被威胁背调

## 使用方式

在支持 Skill 的 AI Agent 里，直接描述你的情况：

> "我被公司辞退了，说我绩效不达标，但我的绩效评分一直很好..."
> "公司要裁员，给了我一份协议让我签字..."
> "老板让我转岗，不去就算旷工处理..."

Agent 自动加载本 Skill，帮你完成五步分析。

---

## 核心原则

> **不要签任何你不理解的文件。**

> **不要在谈判中暴露你的底牌和证据。**

> **拖时间对你有利，公司的举证责任在公司，不在你。**
