# 🛡️ PIP

**被通知"PIP"了？绩效明明正常却被优化？先把这个看完。**

---

## 简单说

这是一个 AI Agent Skill。

你只需要告诉它你的情况——比如"老板突然让我第二天不用来了"，它会告诉你：**你该怎么做、该要多少钱、什么字不能签**。

不需要你懂法律。

---

## 发生了什么事

你应该见过这类场景：

> 早上到公司，HR 把你叫进小会议室，说"公司调整，你的岗位没了"。
> "补偿金会考虑的，先签这个吧。"

大多数人：
- 不知道公司其实违法了
- 不知道该要多少钱
- 被压着当场签字
- 签完才后悔

**但其实——劳动仲裁没有你想的那么难，赔偿金也没有你想的那么少。**

---

## 这个 Skill 能帮你做什么

### 1. 搞清楚状况

你的情况到底是哪一种：
- 公司说你"绩效不达标" → 真的吗？公司能拿出证据吗？
- 公司说"业务调整" → 这算裁员吗？程序合法吗？
- 合同到期不续 → 你有没有权签无固定期限合同？

### 2. 算清楚该拿多少钱

- 正常赔偿：N（每满一年赔一个月）
- 违法解除：2N（双倍）
- 很多人忘要的：未休年假工资、加班费、报销款

### 3. 知道什么字不能签

HR 让你签的任何协议，先拿过来让这个 Skill 帮你过一遍。

尤其是写"因个人原因离职"、"双方无争议"的——**签了可能少拿几万甚至几十万**。

### 4. 知道下一步怎么做

- 怎么收集证据
- 怎么跟公司谈
- 怎么申请仲裁（其实很简单，材料交上去等通知就行）

---

## 适用的情况

- [ ] 突然被 HR / 老板叫去谈话，说你不用来了
- [ ] 绩效评分正常，却收到了 PIP
- [ ] 公司让你签"协商解除协议"或"离职申请"
- [ ] 被强制调岗、降薪、撤门禁
- [ ] 合同到期了公司说不续
- [ ] 被威胁"背调会说坏话"

---

## 使用方法

在 AI Agent 里，直接粘贴下面这段，然后改成你自己的情况：

```
我昨天被 HR 叫去谈话，说我绩效不达标。
我的绩效评分最近一年都是 A/B。
公司让我签一份协议，说会给我补偿金。
我该怎么办？
```

Agent 会自动加载本 Skill，帮你分析。

---

## 三个最重要的原则

> **不要当场签字。** 说"我需要看一下"然后离开，这不会让你少拿钱。

> **不要告诉公司你有哪些证据。** 先听公司说什么，再决定亮什么牌。

> **拖时间对你有利。** 公司比你更想尽快解决。
