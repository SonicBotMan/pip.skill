# 五步框架详解

> 本文件详解劳动维权的核心方法论：定性 → 查据 → 算账 → 谈判 → 行动
> **核验日期**：2026-07-27

---

## 总览

```
第一步：定性 — 这是什么性质的解除？
   ↓
第二步：查据 — 公司能证明自己的理由吗？
   ↓
第三步：算账 — 我实际能拿到多少？
   ↓
第四步：谈判 — 我用什么姿势进场？
   ↓
第五步：行动 — 什么时候仲裁、怎么仲裁？
```

---

## 第一步：定性 — 给公司的解除理由做"三重检验"

### 检验 A：理由是否属于法定理由？

《劳动合同法》规定公司能单方面解除的合法理由只有三类：

| 类型 | 具体理由 | 典型话术 | 后果 |
|------|---------|---------|------|
| 第 39 条（员工过错） | 严重违纪、试用期不合格、刑事责任等 | "你严重违反公司制度" | 程序合规 = 可能合法 |
| 第 40 条（员工无过错） | 不胜任工作、医疗期满、客观情况重大变化 | "你不能胜任这个岗位" | 程序合规 + 满足条件 = 可能合法 |
| 第 41 条（经济性裁员） | 重整、生产困难、技术革新等 | "公司要组织优化/裁员" | 程序合规 + 满足条件 = 可能合法 |

**判断逻辑：**

```
IF 公司说的理由 NOT IN {39条, 40条, 41条} THEN
    → 几乎可以确定违法解除
    → 跳到"第四步：谈判"，目标 2N
ELSE
    → 继续检验 B 和 C
```

### 检验 B：程序是否合规？

即使理由合法，程序也必须合规，否则仍是违法解除：

| 程序要求 | 检查方法 | 不满足的后果 |
|---------|---------|-------------|
| 提前 30 天书面通知 | 有没有书面通知，时间是否够了 | 增加赔偿 |
| 通知工会（如果有） | 直接问公司 HR，"工会有没有收到通知" | 增加赔偿 |
| 出具解除/终止劳动合同证明书 | 离职时必须给，不给可投诉 | 增加赔偿 |
| 理顺社保减员和档案转移 | 离职后 15 日内必须办理 | 增加赔偿 |

**判断逻辑：**

```
IF 理由合法 BUT 程序 NOT 全部满足 THEN
    → 仍是违法解除，只是违法程度较轻
    → 继续算账
```

### 检验 C：绩效"没问题"在法律上的意义（关键）

> 这是关键点：很多公司拿"绩效不达标"说事，但法律上很难证明"不能胜任"。

**关键逻辑：**

```
IF 公司用第 40 条（不能胜任）解除 THEN
    → 公司必须证明三件事：
        1. 有客观考核标准且员工知道（你签过字）
        2. 经过培训或调岗（给你调岗/培训过）
        3. 调岗/培训后仍不能胜任（有新的考核结果）

    IF 公司拿不出以上三份证据 THEN
        → 举证责任在公司，"不能胜任"这条理由站不住
        → 违法解除，2N 赔偿

    ELSE IF 公司有充分证据 THEN
        → 程序合规 + 事实清楚 = 合法解除
        → 此时谈 N+1 补偿
```

**裁判规则来源**：北京三中院 (2025)京03民终16369 号宋某案

> "用人单位依据'不能胜任工作经调岗仍不胜任'为由单方解除劳动合同的，需承担三重举证责任：
> 1. 举证证明劳动者确实不符合明确公示的岗位考核标准
> 2. 举证证明调岗是针对劳动者不胜任情况作出的合理调整
> 3. 举证证明劳动者调岗后仍然不符合岗位要求
> 三者缺一不可，否则将被认定为违法解除。"

详见 [cases/official-cases-2026.md 案例丁](../cases/official-cases-2026.md)。

### 定性结论矩阵

| 检验 A | 检验 B | 检验 C | 定性 | 目标赔偿 |
|-------|-------|-------|------|--------|
| 理由不属于法定 | — | — | 违法解除 | 2N |
| 理由属于法定 | 程序违法 | — | 违法解除（程序） | 2N |
| 理由属于法定 | 程序合规 | 公司举证缺失 | 违法解除（举证不能）| 2N |
| 理由属于法定 | 程序合规 | 公司举证充分 | 合法解除 | N 或 N+1 |
| 协商解除 | — | — | 协商 | N+1 起（可谈）|

## 第二步：查据 — 反向举证

劳动争议中，**举证责任在公司，不在员工**。公司说你违纪、不能胜任，公司必须拿出证据。

### 公司常用理由 vs 公司必须证明什么

| 公司说的理由 | 公司必须证明什么 | 拿不出来怎么办 |
|------------|--------------|-------------|
| "你严重违反制度" | ①制度曾向你公示（你签过字）②制度内容合法合理③违规行为达到"严重"程度 | 程序违法，2N 赔偿 |
| "你不能胜任" | ①考核标准你签过字②给你调岗或培训过③调岗/培训后仍不胜任 | 程序违法，2N 赔偿 |
| "客观情况重大变化" | ①确实发生了客观情况变化②变化达到"重大"程度③无法继续履行合同 | 程序违法，2N 赔偿 |
| "经济性裁员" | ①满足裁员条件②向劳动部门报告过③优先留用了长约员工 | 程序违法，2N 赔偿 |
| "合同到期不续签" | 公司主动不续 → 必须支付 N 补偿金 | 不支付 → 违法，2N 赔偿 |
| "AI 替代你的岗位" | ❌ **不属于客观情况重大变化**（2026 年杭州案、广州案、北京案均明确）| 违法解除，2N |

### 实操建议

- 第一步到第三步：定性、查据、算账 —— 这些在公司找你谈话之前就要准备好
- 第四步：谈判 —— 用这三步的结论去谈，而不是凭感觉

## 第三步：算账 — 三层赔偿金计算

### 第一层：保底数字（依法肯定能拿到的）

| 形式 | 计算方式 | 依据 |
|------|---------|------|
| 违法解除 | **2N 赔偿金** | 《劳动合同法》第 87 条 |
| 合法解除（无过错）| N 或 N+1 | 《劳动合同法》第 40 条、第 46 条 |
| 协商解除 | N+1（最低） | 《劳动合同法》第 36 条 |

**N = 在职年限 × 月均工资**
- 在职年限：6 个月以上算 1 年，不满 6 个月算 0.5 年
- 月均工资：解除前 12 个月平均工资（含奖金/补贴/津贴）
- 上限：超过当地平均工资 3 倍的，基数按 3 倍算，年限最高 12 年

### 第二层：附加可追讨项目（很多人忘记要）

| 项目 | 法律依据 | 说明 |
|------|---------|------|
| 未支付的工资/奖金/报销 | 第 30 条 | 解除前的欠款 |
| 未休年假折算工资 | 《职工带薪年休假条例》 | 未休按 300% 折算 |
| 加班费 | 第 44 条 | 工作日加班 150%，周末 200%，法定节假日 300% |
| 未签劳动合同的双倍工资 | 第 82 条 | 入职超 1 个月未签，第 2 个月起双倍工资，最多 11 个月 |
| **离职前应得绩效工资** | 北京三中院 (2025)京03民终16369 号 | "绩效发放前离职不予发放"条款无效 |
| 未签无固定期限合同的双倍工资 | 第 82 条 | 连续签两次后有权要求签无固定期限，公司拒绝则双倍 |
| 竞业限制补偿金 | 解释一第 38 条 + 解释二第 13-15 条 | 如果签过竞业限制协议，离职后按月支付 |

### 第三层：2025 年新规带来的新武器（解释二）

| 条文 | 可主张 | 适用情形 |
|------|-------|--------|
| **第 19 条** | 公司约定"无需缴纳社保"→ 约定无效；可解除并主张经济补偿 | 公司让签过"放弃社保"协议 |
| **第 19 条** | 因未缴社保导致的损失赔偿 | 公司未缴社保导致医疗/生育/失业保险待遇损失 |
| **第 13 条** | 竞业限制条款不生效 | 非高管，未接触核心商业秘密 |
| **第 18 条** | 违法解除后工资损失按"正常劳动工资"标准 | 选择恢复劳动关系时 |
| **第 16 条** | "劳动合同已经不能继续履行"的 6 种情形 | 高管案可主张恢复劳动关系 + 持续工资损失 |

### 特殊情形的额外筹码

| 形式 | 可主张 | 法律依据 |
|------|-------|---------|
| 公司说"合同到期不续签" | N 补偿金（公司主动不续） | 第 46 条第 5 项 |
| 公司 2 个月不支付竞业限制补偿金 | 书面通知解除竞业限制义务 | 解释一第 38 条 |
| 签了低于法定 80% 的解除协议 | 向仲裁委申请撤销协议 | 解释一第 35 条 |
| 被"事实劳动关系"（合同到期继续工作但没签新合同）| 如果公司终止，最多要 N 补偿金 | 解释二第 11 条 |

详细公式见 [compensation-tiers.md](compensation-tiers.md)。

## 第四步：谈判 — 谈判桌上的四张牌

### 第一张牌：法律牌（最强的牌）

- "根据《劳动合同法》第 87 条，违法解除劳动合同是 2N 赔偿金"
- 亮出这张牌时，同步说出数字 —— "2N 是 X 元，这是法律规定的"
- **适用场景**：公司自知理亏，愿意谈
- **权衡**：先亮数字可能降低赔偿意愿，但建立底线

### 第二张牌：证据牌（底牌，不要轻易亮）

- "我这里有完整的绩效考核记录、工资流水、社保记录"
- **适用场景**：公司在虚构解除理由时，让对方知道你不是好欺负的
- **注意**：不要提前告诉对方你有哪些证据，让对方先亮理由

### 第三张牌：程序牌（针对公司程序漏洞）

- "你们提前 30 天通知了吗？工会收到通知了吗？"
- **适用场景**：公司理由合法但程序不合法，可增加赔偿
- **权衡**：提程序问题可能激化矛盾，但能争取更多补偿

### 第四张牌：时间牌（拖得起的人占优）

- 劳动仲裁 1 年时效，从知道权利被侵害之日起算
- **权衡**：拖延 = 公司要花更多精力应诉 = 公司更愿意谈
- **适用场景**：公司想尽快了结，你反而可以要价更高

详细话术见 [../negotiation/scripts-library.md](../negotiation/scripts-library.md)。

## 第五步：行动 — 仲裁流程

### 仲裁真的不难

- 材料交上去等通知就行，不需要律师（虽然建议请）
- 时效 1 年，你有足够时间准备
- 费用相对低（仲裁费、复印费）

### 什么时候仲裁

- **优先谈判**：仲裁是最后手段，先谈
- **谈判破裂信号**：公司拒绝任何赔偿或给远低于法定的赔偿
- **公司恶意信号**：强行逼签、不给出具证明、拖欠工资等

### 仲裁流程（简化）

1. **准备材料**：解除通知书、工资流水、社保记录、考勤记录、劳动合同
2. **去劳动仲裁委**：通常是公司所在地或劳动合同履行地的仲裁委
3. **填申请表**：写明仲裁请求（2N 赔偿金、未付工资、未休年假等）
4. **等开庭**：通常 30-60 天通知，简易程序 1 次开庭
5. **调解**：开庭前有调解环节，可以达成和解
6. **等裁决**：调解不成的，仲裁委出具裁决书

### 仲裁请求必须列全

> **重要**：提交后过了举证期就**不能变更请求**了。

必包括：
- 2N 违法解除赔偿金
- 工资差额
- 加班费
- 未休年假折算工资
- 未签合同双倍工资差额（如适用）
- 离职前应得绩效工资
- 经济补偿（如选择解除权）
- 因未缴社保导致的损失
- 其他想到的都要写

申请书模板见 [../references/templates/arbitration-application.md](../references/templates/arbitration-application.md)。

## 补充：纠纷预警 — 识别公司经营困境的信号

### 关键洞察

大多数劳动纠纷，在公司找你谈话之前就已经埋下了伏笔。**越早判断，越能主动。**

### 公司陷入困境的常见预警信号

| 信号 | 说明 |
|------|------|
| 无缘无故消失的公务用车 | 节流成本，可能财务紧张 |
| 越来越差的节日福利、下午茶 | 减少成本 |
| 工资发放越来越迟 | 资金链紧张 |
| 中高层员工集中离职 | 可能已有裁员计划或破产风险 |
| 加班工作量异常增加（单人承担多人工作）| 不招新人，压榨现有员工 |
| 老板/高管开始频繁"消失"或情绪异常 | 可能跑路或转移资产 |
| 公司开始严查考勤、报销 | 准备裁员前兆 |
| 公司以"AI 升级"为由调整组织架构 | 可能借 AI 名义裁员 |

**实操**：在决定入职前或在职期间，定期查一查公司是否有大量合同纠纷、欠款诉讼。这些信号出现后，就要开始**暗中收集证据**，做好最坏打算。
