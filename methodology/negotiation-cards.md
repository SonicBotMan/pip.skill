# 谈判四张牌

> 详细说明劳动维权谈判桌上的四张核心牌及其使用策略
> **核验日期**：2026-07-27

---

## 总览

```
谈判四张牌（按使用顺序）
├── 第一张：法律牌（最强，建立底线）
├── 第二张：证据牌（底牌，不轻易亮）
├── 第三张：程序牌（针对公司漏洞）
└── 第四张：时间牌（拖得起的人占优）
```

---

## 第一张牌：法律牌（最强）

### 核心内容

- "根据《劳动合同法》第 87 条，违法解除劳动合同是 2N 赔偿金"
- 亮出这张牌时，**同步说出数字** —— "2N 是 X 元，这是法律规定的"

### 适用场景

- 公司自知理亏，愿意谈
- 谈判刚开始，公司还没提出具体方案
- 你想建立底线

### 权衡

- ✅ **优势**：先亮数字建立底线，公司后续还价有锚点
- ⚠️ **风险**：先亮数字可能降低公司赔偿意愿
- 💡 **策略**：先说法律标准，再说具体数字，给公司留台阶

### 话术示例

```
"根据《劳动合同法》第 87 条，违法解除是 2N 赔偿金。
我在职 3 年 6 个月，月薪 25,000 元，2N = 175,000 元。
这是法律规定的底线，我希望公司能尊重法律标准。"
```

---

## 第二张牌：证据牌（底牌，不要轻易亮）

### 核心原则

> **不要主动告诉对方你有哪些证据**

让公司先亮理由，你针对性反驳。

### 适用场景

- 公司在虚构解除理由时，让对方知道你不是好欺负的
- 公司理由前后矛盾，你掌握反证

### 权衡

- ✅ **优势**：让公司意识到风险，提高赔偿意愿
- ⚠️ **风险**：提前亮牌暴露上限，公司可能针对性准备
- 💡 **策略**：暗示有证据，但不展示具体内容

### 话术示例

```
"公司说我不胜任工作，但我手上有完整的证据链，
包括绩效考核记录、工资流水、培训记录。
如果走仲裁，公司需要承担举证责任。
我希望我们能在桌面上解决问题。"
```

### 禁忌

- ❌ "我有你签字的录音" → 暴露底牌
- ❌ "我有加班打卡记录证明" → 暴露证据类型
- ✅ "我有完整的证据链" → 模糊但有威慑

---

## 第三张牌：程序牌（针对公司程序漏洞）

### 核心内容

质疑公司程序合规性：

- "你们提前 30 天书面通知了吗？"
- "工会收到通知了吗？"
- "解除证明书什么时候给？"
- "社保减员什么时候办？"

### 适用场景

- 公司理由合法但程序不合法
- 公司拒绝出具书面文件
- 增加谈判筹码

### 权衡

- ✅ **优势**：每个程序问题都可增加赔偿
- ⚠️ **风险**：提程序问题可能激化矛盾
- 💡 **策略**：温和提问，不指责

### 话术示例

```
"我注意到本次解除存在程序问题：
1. 没有提前 30 天书面通知
2. 未通知工会
3. 没有出具解除证明书

根据《劳动合同法》第 47 条，违反法定程序的解除行为，
仍需支付赔偿金。程序不合规会让赔偿金额从 N 增加到 2N。

请公司确认：
1. 公司是否愿意按 2N 标准支付赔偿金？
2. 如果公司认为程序合规，请提供书面证明。"
```

## 第四张牌：时间牌（拖得起的人占优）

### 核心内容

- 劳动仲裁 1 年时效，从知道权利被侵害之日起算
- **拖时间对你有利，公司比你更急**

### 适用场景

- 公司想尽快了结
- 你已找到新工作或财务充裕
- 公司有大量类似案件积压

### 权衡

- ✅ **优势**：拖延 = 公司要花更多精力应诉 = 公司更愿意谈
- ⚠️ **风险**：拖延可能让公司降低赔偿意愿，也可能让你错过最佳时机
- 💡 **策略**：设置明确的时间边界，体现"我拖得起，但我也愿意谈"

### 话术示例

```
"我注意到公司已经多次说'回去商量'，但一直没有给我明确答复。

根据《劳动争议调解仲裁法》第 27 条，劳动争议申请仲裁的时效是 1 年。

拖延对我来说不利，但对公司也不利：
1. 我有更多时间收集和固定证据
2. 仲裁时公司会因为拖延被认定为'恶意解除'
3. 仲裁员倾向于保护拖延中受损的劳动者

请公司在 [具体日期] 前给我书面答复：
1. 是否同意 2N 赔偿标准？
2. 如果不同意，公司的赔偿标准是多少？
3. 如果协商不成，我会在 [具体日期] 后申请劳动仲裁。"
```

## 四张牌的组合策略

### 场景 A：公司自知理亏，愿意谈

```
1. 法律牌 → 建立 2N 底线
2. 证据牌（暗示）→ 增加威慑
3. 时间牌 → 设置谈判期限
4. 程序牌 → 备用，如公司挑刺时使用
```

### 场景 B：公司强硬，否认违法

```
1. 程序牌 → 先质疑程序漏洞（最容易证明）
2. 法律牌 → 引用第 87 条
3. 证据牌 → 暗示有完整证据链
4. 时间牌 → 明确"拖得起"
```

### 场景 C：协商解除，公司压价

```
1. 法律牌 → 锚定 2N
2. 时间牌 → 设置期限
3. 备用：第 35 条撤销权（如金额低于法定 80%）
```

### 场景 D：变相解除（拔网线/移门禁）

```
立即取证（拍照/录视频）
→ 直接申请劳动仲裁
→ 主张违法解除 2N
→ 引用 2026 成都付某案作为支撑
```

## 谈判禁忌

### ❌ 禁忌 1：当场签字

无论公司怎么催，**不要当场签任何文件**。
"我需要再想一想" / "我需要咨询律师" → 离开。

### ❌ 禁忌 2：暴露底牌

不要主动说：
- "我只要 N+1 就够了"
- "我没有证据"
- "我急着拿钱"

### ❌ 禁忌 3：被情绪控制

愤怒 = 你不专业 = 你理亏。
保持冷静，用法律和证据说话。

### ❌ 禁忌 4：相信口头承诺

对方口头承诺 → 必须落在纸面。
"明天给你打钱" → 要求书面约定具体日期。

### ❌ 禁忌 5：撤诉换承诺

仲裁中公司承诺给钱让你撤诉 → **没拿到钱千万不要撤诉**。
撤诉后公司反悔，你将无法再次申请仲裁。

## 谈判核心原则

### 原则 1：永远不要在愤怒中谈判

- 情绪失控 = 你不专业 = 你理亏
- 保持冷静，用法律和证据说话

### 原则 2：问开放式问题，让 HR 暴露破绽

- 不是"这不合理"，而是"公司是如何得出这个结论的？"
- 让 HR 解释，让他自己说多错多

### 原则 3：让 HR 做"选择题"而不是"是非题"

- 不是"你同意吗？"，而是"你选方案 A 还是方案 B？"
- 即使 HR 不选，你也占主动

### 原则 4：每句话都要有法律依据或证据支撑

- 不是"我觉得"，而是"根据《劳动合同法》第 X 条"
- 没有证据时，明确说"这个问题需要公司举证"

## 谈判准备清单

谈判前必须准备：

- [ ] 计算好你的 2N 数字
- [ ] 列出所有可主张项目（年假/加班费/绩效等）
- [ ] 准备好证据清单（不展示，但心里有底）
- [ ] 确定你的底线（最低可接受金额）
- [ ] 确定你的理想值（最高期望金额）
- [ ] 准备好"撤退"方案（如谈不成就走仲裁）
- [ ] 设置谈判时间限制
- [ ] 告知一位亲友你的去向（安全考虑）
- [ ] 准备好录音设备（合法告知后使用）
