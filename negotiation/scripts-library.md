# 谈判话术库

> 6 大类话术，针对 HR 不同态度和场景精准怼回
> **核验日期**：2026-07-27（含 2025 年解释二新增主张）

---

## 核心话术原则

### 原则 1：永远不要在愤怒中谈判

情绪失控 = 你不专业 = 你理亏。保持冷静，用法律和证据说话。

### 原则 2：问开放式问题，让 HR 暴露破绽

不是"这不合理"，而是"公司是如何得出这个结论的？"。让 HR 解释，让他自己说多错多。

### 原则 3：让 HR 做"选择题"而不是"是非题"

不是"你同意吗？"，而是"你选方案 A 还是方案 B？"。即使 HR 不选，你也占主动。

### 原则 4：每句话都要有法律依据或证据支撑

不是"我觉得"，而是"根据《劳动合同法》第 X 条"。没有证据时，明确说"这个问题需要公司举证"。

## 分类一：证据博弈话术

### 话术 1：索要绩效考核表

**适用场景**：
- 场景类型：证据博弈 / 程序违规
- HR 态度：强硬 / 拒绝提供
- 公司阶段：谈判初始 / 证据展示

**话术正文**：

```
"我需要看一下公司对我的绩效考核记录，包括考核标准、评分依据、我的签字确认。

根据《劳动合同法》第 40 条，'不能胜任工作'需要证明三件事：
1. 有客观考核标准且员工知道
2. 经过培训或调岗
3. 调岗或培训后仍不能胜任

公司说我不胜任，但拿不出这三份证据，我无法认可这个理由。

参考 2026 年北京三中院 (2025)京03民终16369 号宋某案的裁判规则：
用人单位需承担三重举证责任，三者缺一不可。"
```

**常见反驳及应对**：

| HR 的反驳 | 你的应对 |
|----------|---------|
| "我们回去整理一下再给你" | "好的，请给我书面答复的截止时间，我会等待" |
| "这些是内部文件，不能给员工" | "根据《劳动合同法》第 40 条，考核标准必须向我公示并签字。如果我没有见过这个标准，它不能作为我的考核依据。" |
| "你这是不信任公司" | "这不是信任问题，是法律要求的证据完整性。我需要确认公司是基于什么标准做出的决定。" |

### 话术 2：质疑培训/调岗的真实性

**适用场景**：
- HR 声称你经过了培训或调岗，但拿不出记录
- 公司给的 PIP 实际上只是工作目标，不是培训

**话术正文**：

```
"你说我经过了培训或调岗，但我没有相关记录。

根据《劳动合同法》第 40 条，'经过培训或调岗'必须是有实际操作的，
并且要有培训签到或调岗通知。

请问我：
1. 培训/调岗的起止时间是什么？
2. 培训/调岗的目的是什么？
3. 培训/调岗的结果是什么？
4. 我在哪里签字确认过？

如果公司没有以上记录，那么'经过培训或调岗'这条就不成立。

另外，'绩效改进计划（PIP）'如果只是工作目标和计划，
不构成法律意义上的'培训'。"
```

## 分类二：程序违规话术

### 话术 3：质疑解除程序的合规性

**适用场景**：
- 公司未提前 30 天书面通知
- 未通知工会
- 未出具解除证明书

**话术正文**：

```
"我注意到公司本次解除劳动合同存在程序违规问题：

1. 提前通知不足 30 天
2. 未通知工会（如果公司有工会）
3. 未出具解除/终止劳动合同证明书

根据《劳动合同法》第 47 条，违反法定程序的解除行为，
仍需支付赔偿金。

程序不合规会让赔偿金额从 N 增加到 2N。

请公司确认：
1. 公司是否愿意按 2N 标准支付赔偿金？
2. 如果公司认为程序合规，请提供提前 30 天书面通知的证明。"
```

## 分类三：威胁应对话术

### 话术 4：应对"不签字就停社保/工资"威胁

**适用场景**：
- HR 以"停社保/工资"威胁你签字
- 公司采用强制手段逼迫签约

**话术正文**：

```
"我理解公司希望尽快办结离职手续，但以停社保/工资相威胁是违法的。

根据《劳动合同法》第 30 条，工资必须按月支付，不得克扣。
根据《社会保险法》第 58 条，社保必须按月缴纳，不得停缴。
根据 2025 年 9 月施行的《劳动争议司法解释（二）》第 19 条，
公司让员工签的'自愿放弃社保'协议本身就无效。

如果公司因为我不签字'自愿离职协议'就停我的社保和工资，
这是明显的违法行为。

我会：
1. 立即保留所有威胁证据（录音、截图、书面材料）
2. 向劳动监察部门投诉
3. 在劳动仲裁中主张违法克扣工资和社保的双倍赔偿

建议公司按法定程序办理，避免不必要的法律风险。"
```

### 话术 5：应对"AI 替代岗位"裁员

**适用场景**：
- 公司以"AI 替代你的岗位"为由解除
- 公司声称技术升级导致岗位消失

**话术正文**：

```
"公司以 AI 替代我的岗位为由解除劳动合同，这不属于法律规定的
'客观情况发生重大变化'。

参考 2026 年 4 月杭州市中级人民法院二审的'AI 替岗'案
（周某 vs 某网讯科技公司，2N 赔偿 26 万余元）：

法院认定：
'用人单位以 AI 的成本优势为理由，主动解除劳动关系，
该理由不满足劳动合同无法履行的法定条件。'

AI 引入是公司的主动商业决策，不是不可预见的外部事件。
如果公司仍需要相关人才（如设立了'全案设计师'等新岗位），
说明人才需求并未灭失。

请公司按 2N 标准支付违法解除赔偿金。"
```

### 话术 6：应对变相解除（拔网线/移门禁/移出群）

**适用场景**：
- 公司不直接发解除通知
- 但通过剥夺劳动条件逼迫你离职

**话术正文**：

```
"公司今天连续实施以下行为：
1. 取消我的门禁及考勤打卡权限
2. 拔除我的工作电脑网线
3. 将我移出工作群
4. 解除我的工作账号运营者身份

参考 2026 年成都市中级人民法院'五一'典型案例 1
（付某 vs 某科技公司案）：

法院认定：
用人单位剥夺劳动者基本劳动条件的多项紧密行为，
构成'事实上单方违法解除劳动合同'。

我现在拍照 + 录视频取证。
如果公司不立即恢复我的劳动条件，
我将直接申请劳动仲裁，主张违法解除 2N 赔偿金。"
```

## 分类四：协商策略话术

### 话术 7：锚定 2N 高赔偿目标

**适用场景**：
- 谈判刚开始，公司还没提出具体方案
- 公司自知理亏，愿意谈

**话术正文**：

```
"根据《劳动合同法》第 87 条，违法解除劳动合同，
公司应当支付 2N 赔偿金。

我的基本情况：
- 在职年限：X 年 X 个月
- 月均工资：Y 元（含奖金/补贴）
- 法定赔偿金额：2N = 2 × (X × Y) = Z 元

这是我的底线，我希望公司能尊重法律标准。

如果公司认为我的理解有误，请书面说明：
1. 认为的解除理由是什么？
2. 认为的赔偿标准是什么？
3. 如与我的理解不同，法律依据是什么？

请公司在 X 日内给我书面答复。"
```

### 话术 8：识别"陷阱条款"

**适用场景**：
- 公司给的协议里有"账户解封后支付"、"经营改善后支付"等不确定条件

**话术正文**：

```
"我注意到协议中有一条：
'因公司账户冻结/经营困难，补偿金将于 XX 条件成就后支付'

参考 2025 年北京市劳动人事争议仲裁十大典型案例 3：
这种条款被认定为'陷阱条款'——
利用劳动者缔约弱势地位，
将企业经营风险转嫁给劳动者，
依《劳动合同法》第 26 条应属无效。

我要求将支付条件修改为：
'公司于 X 年 X 月 X 日前一次性支付全额补偿金'

否则我不签这份协议。"
```

## 分类五：拖延应对话术

### 话术 9：设置谈判时间边界

**适用场景**：
- 公司多次拖延，说"回去商量"、"再研究一下"
- 没有明确答复

**话术正文**：

```
"我注意到公司已经多次说'回去商量'、'再研究一下'，
但一直没有给我明确答复。

根据《劳动争议调解仲裁法》第 27 条，
劳动争议申请仲裁的时效是 1 年。

拖延对我来说不利，但对公司也不利：
1. 我有更多时间收集和固定证据
2. 仲裁时公司会因为拖延被认定为'恶意解除'
3. 仲裁员倾向于保护拖延中受损的劳动者

请公司在 [具体日期] 前给我书面答复：
1. 是否同意 2N 赔偿标准？
2. 如果不同意，公司的赔偿标准是多少？
3. 如果协商不成，我会在 [具体日期] 后申请劳动仲裁。"
```

## 分类六：2025 年新规主张话术

### 话术 10：主张"放弃社保"协议无效（解释二第 19 条）⭐

**适用场景**：
- 公司让你签过"自愿放弃社保"协议
- 公司以"员工自愿放弃"为由不缴社保

**话术正文**：

```
"公司此前让我签署的《自愿放弃社保协议》，
根据 2025 年 9 月 1 日施行的
《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》
第 19 条：

'用人单位与劳动者约定或者劳动者向用人单位承诺
无需缴纳社会保险费的，人民法院应当认定该约定或者承诺无效。'

该协议依法无效。

我现在正式通知公司：
1. 依据《劳动合同法》第 38 条第 1 款第 3 项解除劳动合同
2. 要求公司支付经济补偿 N = X 元
3. 要求公司补缴在职期间的全部社会保险
4. 如有因未缴社保导致的损失（医疗费/生育津贴等），要求赔偿"
```

### 话术 11：主张竞业限制条款不生效（解释二第 13 条）

**适用场景**：
- 你不是高管/高级技术人员
- 公司主张高额竞业限制违约金
- 你的岗位未接触核心商业秘密

**话术正文**：

```
"公司主张我违反竞业限制约定，需支付违约金 X 万元。

但根据 2025 年 9 月 1 日施行的
《劳动争议司法解释（二）》第 13 条：

'劳动者未知悉、接触用人单位的商业秘密和与知识产权相关的保密事项，
劳动者请求确认竞业限制条款不生效的，人民法院依法予以支持。'

我的岗位是 [具体岗位]，不属于高级管理人员或高级技术人员。
我在日常工作中仅接触公司的一般经营信息，
从未接触核心商业秘密或与知识产权相关的保密事项。

参考 2025 年第四批典型案例 5（李某 vs 某保安公司案）：
保安岗位被认定为非竞业限制适格主体，违约金 20 万被驳回。

我主张：
1. 确认竞业限制条款对我不生效
2. 不承担违约金
3. 公司应停止竞业限制补偿金支付"
```

## 谈判现场注意事项

### 1. 录音要合法

约谈开始前告知：

```
"本次谈话将进行录音，以保障我们双方的合法权益。"
```

只有告知后的录音才能作为合法证据。

### 2. 不要当场做决定

被要求当场签字 → "我需要再想一想" / "我需要咨询律师"

### 3. 看清楚再签

如果是协商解除协议，重点检查：

- 赔偿金是否包含：加班费（平日 1.5 倍/周末 2 倍/法定节假日 3 倍）
- 年终奖按时间折算的金额
- "过期"加班时长的赔偿
- 社保公积金交到几月
- 股票归属方案
- **支付条件是否含"陷阱条款"**（如"账户解封后支付"）

### 4. 反向思考

为什么 HR 这么急着让你签 N+1？如果公司违法解除，2N 才是法定标准。

## 仲裁庭审话术

### 开庭陈述模板

```
"尊敬的仲裁员：

我是申请人 XX，于 X 年 X 月入职被申请人 XX 公司，担任 XX 岗位。

X 年 X 月 X 日，被申请人以 [公司理由] 为由单方解除劳动合同。
我认为该解除行为违法，理由如下：

第一，[法律分析：理由不成立]
[具体阐述]

第二，[法律分析：程序违法]
[具体阐述]

第三，[法律分析：举证不足]
[具体阐述]

综上，被申请人的解除行为构成违法解除，
应当依《劳动合同法》第 87 条支付 2N 赔偿金 X 元。

同时，被申请人还应支付：
- 未休年假折算工资 X 元
- 加班费 X 元
- 离职前应得绩效 X 元
- [其他主张]

请仲裁庭依法支持申请人的请求。"
```

### 举证环节话术

```
"申请人提交证据 X：
[证据名称]，证明 [证明目的]。

该证据形成于 [时间]，来源合法。
请仲裁庭予以采信。"
```

### 质证环节话术（应对公司证据）

```
"申请人对被申请人提交的证据 X 的真实性/合法性/关联性有异议：

[具体问题]

该证据不能证明被申请人的主张，
请仲裁庭不予采信。"
```

### 庭审结束陈述

```
"申请人坚持全部仲裁请求。

本案事实清楚，法律依据明确。
请仲裁庭依法裁决，支持申请人的全部请求。"
```

## 心态建设

### 最常见的放弃时机

- 被 HR 约谈后，被威胁套路吓到
- 仲裁立案后，觉得太麻烦放弃
- 调解阶段被公司给点小钱就接受

### 必须做好的心理建设

1. **不要抱有任何幻想**——走到仲裁就是撕破脸了
2. **坚定信念，不要轻敌**——很多劳动者还没迈开步子就放弃了
3. **拖时间对你有利**——公司要花精力应诉，公司更急着解决
4. **仲裁期间不要撤诉**——没拿到钱就撤 = 前功尽弃
5. **不要被口头承诺骗了**——对方拖延时间的手段
