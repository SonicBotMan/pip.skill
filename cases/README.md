## 📝 案例评级标准

### ⭐⭐⭐⭐⭐ 极高（项目核心场景）

- 案号完整、判决书关键论述清晰
- 与项目 PIP/AI 替代/协商解除核心场景直接对应
- 法院二审或仲裁委典型案例

### ⭐⭐⭐⭐ 高

- 法院或仲裁委发布
- 与项目场景相关
- 可作为重要参考

### ⭐⭐⭐ 中

- 官方发布
- 与项目部分场景相关
- 辅助参考

### ⭐⭐ 低

- 反向参考（公司视角案例）
- 或场景较窄

### ⭐ 很低

- 仅作背景了解
- 不直接影响项目判断

## 🔍 案例使用规范

### 在 SKILL.md / 方法论中引用案例

```markdown
> **裁判规则来源**：北京三中院 (2025)京03民终16369 号宋某案
> 详见 `cases/official-cases-2026.md` 案例丁
```

### 在用户回答中引用案例

```markdown
**类似案例参考**：
- [2026 杭州中院 AI 替岗案](official-cases-2026.md#案例甲)：周某 vs 某网讯科技公司，2N 赔偿 26 万余元
- 你的情况与该案高度相似，建议参照其裁判逻辑主张权利
```

### 引用律所转述案例（必须标注）

```markdown
> 据律所文章转述（来源：XX 律所，案号未核），[案例描述]。
> ⚠️ 本案例来自律所转述，未经裁判文书网核验。
```

## 🔄 案例库维护

### 新增案例流程

1. 核验来源可信度（🟢/🟡/🔴）
2. 收集完整案件信息（当事人脱敏、案号、法院、判决要点）
3. 保存原始文件到 `research/sources/03-cases/`
4. 在对应年份文件中新增条目
5. 在 `research/indexes/evidence-index.md` 登记
6. 更新 `CHANGELOG.md`

### 案例核验流程

参见 `../CONTRIBUTING.md` 的「案例贡献规范」。

### 定期核验频率

- 每季度关注 court.gov.cn 新发布的典型案例
- 每年 1 月核验所有引用案例的判决书是否仍可在裁判文书网检索
- 发现新司法解释出台 → 立即核验现有案例是否仍适用
