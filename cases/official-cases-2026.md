## 案例甲：杭州中院"AI 替岗"案（2026-04 二审）⭐ landmark

### 基础信息

| 字段 | 内容 |
|------|------|
| **案件名称** | 某网讯科技公司与周某劳动争议案 |
| **当事人** | 周某（化名"小周"、"周维"），35 岁 |
| **公司** | 某网讯科技公司（杭州） |
| **岗位** | AI 大模型"问句质检"主管 |
| **原月薪** | **25,000 元** |
| **公司提议** | 调岗至普通运营岗，月薪 **15,000 元（降 40%）** |
| **解除日期** | 2025-01 |
| **仲裁委** | 杭州市余杭区劳动人事争议仲裁委员会 |
| **一审** | 杭州市余杭区人民法院（2025-12 判决） |
| **二审** | **杭州市中级人民法院民五庭**（2026-04 判决） |
| **承办法官** | **施国强** |
| **庭长** | 丁晔 |
| **判决结果** | 违法解除，2N 赔偿金 **26 万余元** |
| **可信度** | 🟢 官方一手（法院官方发布 + 8 个权威媒体印证） |

### 案件经过

1. 周某在某网讯科技公司从事"问句质检"工作（负责对 AI 大模型与用户交互生成的答案进行正确性判定）
2. 2025-01 公司以"项目组织结构调整"为由，提议将周某从主管调至普通岗位，月薪从 25,000 元降至 15,000 元
3. 周某拒绝调岗方案
4. 公司单方解除劳动合同
5. 直到仲裁庭审，公司才告知裁员真实理由：**"AI 大模型技术升级，原来需要人工完成的质检工作，现在 AI 自己就能做了"**

### 三级裁决一致性

- **仲裁**：违法解除，赔偿 26 万余元
- **一审（余杭法院）**：驳回公司诉讼请求
- **二审（杭州中院）**：驳回上诉，维持原判

### 判决书关键论述

> "用人单位以 AI 的成本优势为理由，主动解除劳动关系，该理由不满足'劳动合同无法履行'的法定条件。"

> "该公司为小周提供的新岗位待遇大幅下降，并非合理的协商方案。"

> "人工智能技术的发展本应用于解放劳动、促进就业、福祉民生，劳动法允许用工单位承接技术变革进行更新转型，但亦应顾及保障劳动者的合法权益。"

### 法律依据

- **《劳动合同法》第 40 条第 3 项被否定**——公司主张"客观情况发生重大变化"不成立
- AI 引入是公司的主动商业决策，非不可预见外部事件

### 基础信息

| 字段 | 内容 |
|------|------|
| **当事人** | 魏某 |
| **公司** | 某智能公司 |
| **岗位** | 平面设计师（3 年多） |
| **公司主张** | AI 可取代平面设计 → 取消岗位 → 设新岗"全案设计师" |
| **解除时已付** | 经济补偿 33,000 元 + 代通知金 8,000 元 = 41,000 元 |
| **一审** | 广州市南沙区人民法院 |
| **二审** | **广州市中级人民法院**（2026-06 判决） |
| **经办法官** | **陈诗媛** |
| **判决结果** | 违法解除，赔偿金差额 **35,000 元** |
| **可信度** | 🟢 权威财经媒体（21 经济网）+ 央广网/光明网/中青网/新浪财经印证 |

### 案件经过

1. 魏某在某智能公司担任平面设计师
2. 公司进行组织架构调整，取消原平面设计师岗位，新设"全案设计师"等岗位
3. 公司主张：原平面设计工作可由 AI 技术取代，构成"客观情况发生重大变化"
4. 公司仅就离职补偿与魏某协商，未就调岗至"全案设计师"进行实质沟通
5. 公司出具《解除劳动合同通知书》，已支付 N+1（4.1 万）
6. 魏某不服，提起劳动仲裁后诉至法院

### 三级裁决

- **仲裁**：认定公司不存在违法解除，驳回魏某关于赔偿金的请求
- **一审（南沙区法院）**：公司支付违法解除赔偿金差额 3.5 万
- **二审（广州中院）**：驳回上诉，维持原判

### 判决书关键论述

> "某智能公司虽主张平面设计工作可由 AI 部分替代，但从其同时提出可为魏某调整至'全案设计师'岗位可知，**公司对设计类人才的需求并未因 AI 技术引入而根本灭失**。"

> "AI 替代劳动者岗位的技术升级是否属于'客观情况发生重大变化'，不能一概而论，须结合该技术对特定行业、特定岗位的替代是否已达到不可抗拒、不可预见且超出用人单位合理控制的程度进行判断。"

> "即便客观情况发生重大变化，用人单位亦须履行与劳动者协商变更劳动合同的前置程序。"

### 法律依据

- **《劳动合同法》第 40 条第 3 项不适用**——公司自主经营决策不属"客观情况重大变化"
- 公司未履行"协商变更劳动合同"的前置程序

### 8 个案例目录

#### 案例 1：付某 vs 某科技公司 — 变相解除 = 违法解除 ⭐⭐⭐⭐⭐

**裁判规则**：用人单位剥夺劳动者基本劳动条件（拔网线/移门禁/移出工作群）= 违法解除

**基本事实**：
- 付某 2021-10-13 入职某科技公司，从事视频剪辑及视频运营
- 2024-12 公司安排其至招商部从事非原岗位工作
- 2025-02-10 公司发调岗通知书，将付某调至客户管家岗位
- 付某次日回函对调岗提出异议
- **2025-02-11 至 13 日公司连续实施**：
  - 解除付某视频号运营者身份
  - **拔除工作电脑网线**
  - **取消门禁及考勤打卡权限**
  - **移出工作群**
- 致付某无法进入工作场所开展工作

**裁判结果**：高新法院判令公司承担违法解除劳动合同的赔偿责任

**典型意义**：确立了"非合理事由＋多项紧密行为＋剥夺劳动条件致无法履职"的裁判规则

**项目相关性**：⭐⭐⭐⭐⭐ 与项目"调岗逼迫"场景**直接相关**

#### 案例 3：李某 vs 某运输公司 — 劳务外包模式下工龄连续计算 ⭐⭐⭐

**裁判规则**：非因本人原因变更劳动关系主体 + 基于非真实意思出具离职申请 → 工龄连续计算

**基本事实**：
- 李某 2017-08 起先后与甲、乙、丙、丁 4 家公司签订劳动合同
- 均约定到某运输公司从事服务外包站点驾驶员工作

- 2025-08-01 丁公司外包合同到期，李某劳动关系转移至戊公司

#### 案例 4：陈某 vs 某科技公司 — 试用期"不符合录用条件"三重刚性要件 ⭐⭐⭐⭐⭐

**裁判规则**：试用期"不符合录用条件"解除合法性的"三重刚性要件"

**基本事实**：
- 陈某 2025-07-10 入职某科技公司，担任销售经理
- 试用期 6 个月
- 2025-08-12 公司制定《销售人员工作手册》明确试用期销售人员不设定销售任务
- 2025-10-31 公司以"自入职以来至今无销售业务量产生"为由解除

**裁决结果**：成都市劳动人事争议仲裁委员会支持陈某，公司支付违法解除赔偿金

**裁判要点**：
1. **明确的制度依据**（录用条件及标准）
2. **充分的客观证据**（用人单位的考核过程及结果）
3. **正当的实施程序**（明确告知）

**三者缺一不可**，否则构成违法解除。

**项目相关性**：⭐⭐⭐⭐⭐ 与 PIP/试用期场景**直接相关**

### 关键裁判规则（项目最重要的裁判规则之一）

#### "不能胜任工作经调岗仍不胜任"解除的三重举证责任

> 用人单位需承担**三重举证责任**：
>
> 1. 举证证明劳动者确实**不符合明确公示的岗位考核标准**、存在不能胜任原岗位的客观事实
> 2. 举证证明调岗是**针对劳动者不胜任情况作出的合理调整**（非随意调岗）
> 3. 举证证明劳动者调岗后**仍然不符合岗位要求**
>
> **三者缺一不可，否则违法解除。**

#### "绩效发放前离职不予发放"条款无效

> 若用人单位系违法解除劳动关系，其内部制度中"绩效发放前离职不予发放"的条款属于**免除自身法定责任、排除劳动者获得劳动报酬权利的格式条款**，依法应属无效。

### 法律依据

- 《劳动合同法》第 40 条（不能胜任解除条件）
- 《劳动合同法》第 87 条（违法解除 2N 赔偿金）
- 《劳动合同法》第 26 条第 1 款（格式条款无效情形）
- 《劳动争议调解仲裁法》第 6 条（举证责任）
