# 投诉/举报信模板

> 用途：向劳动监察大队投诉公司违法行为，可单独使用，也可配合仲裁一起使用  
> 劳动监察大队可以调查取证、责令整改、处罚用人单位，效率较高，适合部分问题

---

## 模板一：劳动监察投诉书（要求查处违法行为）

```
劳动监察投诉/举报书

投诉人（用人单位）：__________
姓名：__________  身份证号：__________________
联系电话：_______________
住址：________________________

被投诉人（用人单位）：
名称：________________________________
统一社会信用代码：__________________
注册地址：____________________________
法定代表人：__________  联系电话：__________

---

【投诉事项】

投诉人请求劳动监察大队依法查处被投诉人的下列违法行为：

1. 【违法解除劳动合同】
   被投诉人于____年____月____日在没有正当理由的情况下违法单方面解除与投诉人的劳动合同，违反《劳动合同法》第39/40/41/48条（根据实际情况选一条）。

2. 【未支付违法解除赔偿金】
   被投诉人拒绝支付违法解除劳动合同的2N赔偿金，违反《劳动合同法》第87条。

3. 【未出具解除/终止劳动合同证明书】
   被投诉人至今未向投诉人出具《解除/终止劳动合同证明书》，违反《劳动合同法》第50条。

4. 【未办理社保减员/档案转移手续】
   被投诉人拒绝/拖延为投诉人办理社会保险关系转移/人事档案转移手续，违反《劳动合同法》第50条。

5. 【未支付工资/加班费】（如有）
   被投诉人拖欠投诉人____年____月____日至____年____月____日工资/加班费共计____元，违反《工资支付暂行规定》。

（以上事项根据你的实际情况选择保留或删除）

---

【事实经过】

投诉人于____年____月____日入职被投诉人处，担任____（岗位），签订了书面劳动合同，合同期限____年。

____年____月____日，被投诉人在无任何正当理由的情况下向投诉人提出解除劳动合同（具体理由：________），既未提前30日书面通知，也未支付任何赔偿。

投诉人认为，被投诉人的上述行为严重违反劳动法律法规的规定，损害了投诉人的合法权益。

投诉人多次与被投诉人协商处理此事，均未得到合理回应。现依法向贵大队投诉，请求依法调查处理。

---

【证据材料】

1. 劳动合同复印件
2. 解除/终止劳动合同通知书复印件（如有）
3. 工资条/银行流水复印件
4. 社保缴费记录复印件
5. 微信聊天记录/邮件/录音（证据名称：________）
6. 其他证据：________________

---

【投诉请求】

1. 请求依法对被投诉人的违法行为进行查处；
2. 请求责令被投诉人立即支付违法解除劳动合同赔偿金____元；
3. 请求责令被投诉人立即出具《解除/终止劳动合同证明书》；
4. 请求责令被投诉人立即办理社会保险关系转移/人事档案转移手续；
5. 请求责令被投诉人立即支付拖欠的工资/加班费____元；
6. 其他请求：________________

---

此致

__________人力资源和社会保障局
劳动监察大队

投诉人（签名）：________________
____年____月____日

附：证据材料副本____份
```

## 模板二：社保险种投诉（仅针对社保问题）

```
劳动监察投诉书（社保专项）

投诉人：____，身份证号____________，电话____
被投诉人：____公司，统一社会信用代码____

投诉事项：
1. 被投诉人未为投诉人缴纳____年____月至____年____月的社会保险（险种：养老/医疗/工伤/失业/生育），共计少缴____个月；
2. 被投诉人在劳动合同解除后拒绝为投诉人办理社保减员手续。

事实：
投诉人于____年____月____日入职，____年____月____日离职。在职期间，公司未依法全额缴纳社保。（或：离职后公司拒绝办理社保减员，导致投诉人无法在新单位参保。）

请求：
1. 责令被投诉人补缴少缴的社会保险；
2. 责令被投诉人立即办理社保减员手续；
3. 如存在断缴，责令被投诉人补缴断缴期间的社保。

此致
__________人力资源和社会保障局
劳动监察大队

投诉人：____  日期：____年____月____日
```

## 投诉渠道

### 线下渠道
- **公司注册地或实际经营地**的区县人力资源和社会保障局劳动监察大队
- 携带身份证、劳动合同、证据材料原件及复印件

### 线上渠道（各地略有差异）
- **全国根治欠薪线索反映平台**：微信搜索"国务院根治拖欠农民工工资工作领导小组办公室"
- **当地人社局官网/公众号**：如"北京人社"公众号 → 劳动监察投诉
- **12333热线**：全国人力资源和社会保障服务热线
- **国家人社部官网**：www.mohrss.gov.cn

### 注意事项
- 劳动监察处理时效：一般60天内结案，复杂案件可延长30天
- 劳动监察只能处理部分问题（如：工资拖欠、社保欠缴、不出具离职证明）
- **违法解除赔偿金**问题必须走仲裁程序，劳动监察不受理
- 两个渠道可以**同时走**，互不影响
