# 劳动仲裁申请书模板

> 使用说明：将_____处替换为你的实际信息。括号内文字为说明，可删除。

---

## 模板一：完整版（违法解除赔偿金 + 工资/社保诉求）

```
劳动人事争议仲裁申请书

（本申请书适用于：公司违法单方解除劳动合同，员工主张2N赔偿金及附带的工资、社保、档案转移等诉求）

---

申请人（劳动者）：
姓名：__________
性别：____
身份证号：______________________
出生日期：____年____月____日
联系电话：_______________
现住址：______________________

委托代理人（如有）：
姓名：__________ 联系电话：__________
代理权限：□一般代理  □特别授权（代为承认、变更、放弃仲裁请求，代为和解、调解）

被申请人（用人单位）：
单位名称：________________________________________（与营业执照一致）
统一社会信用代码：________________________
注册地址：________________________________________
实际经营地址：________________________________________
法定代表人：__________  职务：__________  联系电话：_______________

---

【请求事项】

1. 请求裁决被申请人支付违法解除劳动合同赔偿金人民币（大写）__________元整（¥__________），即2N赔偿；
2. 请求裁决被申请人支付____年____月____日至____年____月____日期间的工资人民币（大写）__________元整（¥__________）；
3. 请求裁决被申请人出具《解除/终止劳动合同证明书》；
4. 请求裁决被申请人办理社会保险关系转移手续；
5. 请求裁决被申请人办理人事档案转移手续；
6. 其他请求：________________________

（以上第2-6项根据你的实际情况选择保留或删除）

---

【事实与理由】

申请人于____年____月____日入职被申请人处，担任__________（岗位/职位），双方签订了书面劳动合同，合同期限为____年____月____日至____年____月____日。

申请人在职期间，认真履行工作职责，最近一次绩效考核结果为__________（优秀/良好/称职），绩效评估记录显示申请人工作表现正常，不存在不胜任工作的情况。

____年____月____日，被申请人突然向申请人提出解除劳动合同，声称解除理由为"__________"（填写公司给出的理由，如：绩效不佳/组织优化/经济性裁员/客观情况变化等）。

申请人认为，被申请人上述解除劳动合同的行为违法，具体理由如下：

1. 【法律分析一：理由不成立】
   申请人的绩效评估结果为__________，不存在公司所称的"绩效不佳"/"不能胜任工作"的情形。
   即使公司主张"不胜任工作"，根据《劳动合同法》第40条，也应当首先对申请人进行培训或调岗，而公司未履行上述程序。
   公司援引的解除理由缺乏事实和法律依据。

2. 【法律分析二：程序违法】
   公司在解除劳动合同前，未提前30日以书面形式通知申请人 / 未支付代通知金（根据实际情况删除或保留）。
   公司未依法将解除理由通知工会（适用于有工会的单位）。
   公司未出具书面的解除/终止劳动合同证明书，程序严重违法。

3. 【法律分析三：违法解除的法律后果】
   根据《劳动合同法》第48条，用人单位违反本法规定解除劳动合同的，劳动者可以要求继续履行劳动合同，或者要求支付赔偿金。
   申请人现选择要求被申请人支付违法解除劳动合同的赔偿金。

综上，被申请人违法单方面解除劳动合同，严重侵犯了申请人的合法权益。申请人多次与被申请人协商未果，现依法向贵仲裁委员会申请仲裁，请求依法支持申请人的上述请求。

---

【证据清单】

申请人将提交以下证据材料：

1. 劳动合同原件 ____份
   → 证明：双方存在劳动关系，合同期限，岗位约定

2. 解除/终止劳动合同通知书原件/复印件 ____份
   → 证明：公司解除的事实及解除理由

3. 工资条/银行工资流水（____年____月至____年____月）____份
   → 证明：月均工资标准，劳动关系存续期间

4. 社保缴费记录（____年____月至____年____月）____份
   → 证明：社保缴纳情况，劳动关系存续期间

5. 绩效考核记录/评估表/绩效邮件 ____份
   → 证明：绩效评估结果正常，不存在"不胜任工作"的情形

6. 考勤记录（公司系统截图/打卡记录）____份
   → 证明：正常出勤

7. 工作成果材料（项目文件/邮件往来/业绩证明）____份
   → 证明：正常工作，履行了工作职责

8. 与公司/HR的沟通记录（微信截图/邮件/录音）____份
   → 证明：公司违法解除的事实，协商过程

9. 公积金缴纳记录 ____份
   → 证明：劳动关系存续期间

10. 其他证据：________________________

---

【赔偿金计算方式】

申请人的赔偿金计算如下：

在职年限：____年____月（即____年，按一年=1个月工资计算）
月均工资：人民币（大写）__________元整（¥__________）（指解除前12个月平均工资，含奖金/津贴）

经济补偿金 N = 在职年限 × 月均工资 = ____ × ____ = ____元
违法解除赔偿金 2N = N × 2 = ____元

---

此致

申请人（签名）：________________

　　证据材料副本____份
```

## 模板二：简洁版（违法解除，只主张2N赔偿金）

```

1. 违法解除劳动合同赔偿金2N = ____元（计算：____年 × ____元/月 × 2）

3. 办理社保/档案转移
```

## 填写注意事项

1. **被申请人信息**：必须与营业执照上的公司全称一致，统一社会信用代码可在国家企业信用信息公示系统查询
2. **管辖仲裁委**：一般选择公司注册地或劳动合同实际履行地的仲裁委
3. **赔偿金计算**：用实际数字，不要用估算，如有争议可在庭审中补充证据
4. **证据副本**：提交仲裁委的份数 = 被申请人数量 + 1
5. **录音证据**：如提交录音作为证据，需将录音刻盘并附文字稿
6. **时效**：从知道权利被侵害之日起1年内提交，不要拖
