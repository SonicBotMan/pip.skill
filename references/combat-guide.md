## 一、识别公司经营困境的预警信号

公司在经营困境时，高层会极力隐瞒，但细节会暴露：

- 无缘无故消失的公务用车
- 越来越差的节日福利 / 下午茶
- 越来越迟的薪水发放
- 中高层员工集中离职
- 企查查/天眼查出现大量合同纠纷案（标的数十万到数百万）

**越早判断，越能避免陷入纠纷。**

## 二、"协商"谈判的核心原则

### 最核心原则：不要签字！

公司"协商离职" = 披着合法外衣的违法裁员。
只要**不签字 + 保留好证据** = 你就没事。

### 四种结局分析

| 方案 | 员工收益 | 公司收益 | 适用场景 |
|------|---------|---------|---------|
| 1. 顺着公司"协商" | 最小的补偿权益，损失维权和发声权益 | 最大，全身而退 | 员工急于脱身、无力维权 |
| 2. 仲裁 | 拿到应得的补偿，不受条款制约 | 承担仲裁败诉风险 | 员工有一定时间和精力 |
| 3. 让公司合法裁员 | N+1 | 依法裁员，程序合规 | 公司愿意走正规程序 |
| 4. 真正的好聚好散 | 补偿+股票，好聚好散 | 减少违法记录 | 双方都有诚意 |

### 协商的正确姿势

**开口就说：**
> "请跟我的律师谈。"（律师咨询费约 1000 元左右）

**协商时：**
- 说出你的权益清单：2N、股票、未休年假折算、加班费等
- 协议上不合理的格式条款全部删掉
- 对方口头承诺 → 要求落在纸面；不能落在纸面 → 约定具体时效

**千万不能做：**
- 主动提交离职申请（一提就失去回头路）
- 签署任何对自己不利的文件
- 被现场压力影响判断

### HR 不会告诉你的真相

- 只要**不主动提离职**，公司只能通过谈条件让你主动离职
- 企业痛快给钱 = 让你自己提离职 = 企业免责
- 一般协商条件 ≥ N+1（不会主动给 2N，除非你能证明违法解除）
- 如果条件不满意 → **可以熬着**，在公司待着实际比仲裁容易

## 三、谈判过程实操细节

### 约谈现场操作规范

1. **录音要合法**：约谈开始前告知"本次谈话将进行录音，以保障我们双方的合法权益。"（只有告知后的录音才能作为合法证据）

2. **不要当场做决定**：被要求当场签字 → "我需要再想一想。"

3. **看清楚再签**：
   - 赔偿金是否包含：加班费（平日 1.5 倍/周末 2 倍/法定节假日 3 倍）
   - 年终奖按时间折算的金额
   - "过期"加班时长的赔偿
   - 社保公积金交到几月
   - 股票归属方案

4. **反向思考**：为什么 HR 这么急着让你签 N+1？

### 仲裁进行中的操作

- 仲裁可以**一边上班一边进行**
- 最多只需请几次假
- **可以不选调解**（直接加快进度）
- **没拿到钱千万不要撤诉**
- 降薪或拖欠工资 → 可**立即离职** + 边找新工作边仲裁

## 四、面对威胁和套路话的应对

### 套路 1：口头辞退（"明天不用来了"）

- **法律认定**：口头辞退 = **无效**，不能听
- **如果你真的不去**：缺勤 3 天后，公司可依法以"严重违反规章制度"开除你 → 拿不到赔偿
- **应对**：继续正常打卡上班

### 套路 2：取消门禁权限 / 没收电脑 / 取消打卡权限 / 拔网线 / 移出工作群

- **法律认定**：这是公司**单方面违法解除劳动合同**（2026 年成都中院典型案例 1 付某案已明确）
- **应对**：拍照 + 在公司门口录视频取证 → 直接去劳动仲裁

### 套路 3：降薪 / 取消福利

- **法律认定**：超过 1 个月不提出异议 = 法律默认你接受了降薪
- **应对**：知道降薪的**第一时间**就去仲裁，不要等

### 套路 4：无薪长假 / 无薪调休

- **法律认定**：《工资支付暂行规定》——非因劳动者原因停工停产，一个工资支付周期内工资照付；超出一个周期，提供正常劳动的不得低于最低工资
- **应对**：无薪长假 = 违法，向劳动监察部门投诉

### 套路 5：调岗（逼迫自己辞职）

- **法律认定**：单方调岗 = **变更劳动合同**，须双方协商一致
- **应对**：
  - 新岗位不是你的专业 / 无法胜任 → 提出异议
  - 公司以此迫使你离职 → 公司承担责任

### 套路 6：取消或减少福利

- **法律认定**：社保是强制性的，不能取消
- **法律认定**：劳动合同/规章制度约定的福利，不能单方减少
- **2025 年新武器**：解释（二）第 19 条——公司让签"自愿放弃社保"协议 → **协议无效**

### 套路 7：HR 威胁"背调会说坏话"

- **法律认定**：《就业促进法》——公司做虚假负面评价 = 侵权
- **事实**：现在背调一般只联系 HR，不联系部门负责人；背调只核客观事实
- **应对**：保留追究的权利

### 套路 8："你不签字就 XXX"

- **关键**：只有**拿刀威胁**才算法律意义上的胁迫
- **不要被吓到**：保持冷静，不要在压力下签字

### 套路 9：AI 替代岗位

- **法律认定**（2026 年杭州中院周某案 + 广州中院魏某案 + 北京刘某案）：AI 替代不属"客观情况重大变化"
- **应对**：
  - 拒绝以"AI 替代"为由的解除
  - 主张 2N 赔偿金
  - 如公司仍设相近岗位（如"全案设计师"），主张人才需求未灭失

### 套路 10：PIP（绩效改进计划）

- **法律认定**：PIP 本身不等于"培训"——若 PIP 仅为工作目标/计划，不构成法律意义上的培训（北京某移动软件公司何某案）
- **应对**：
  - 不主动拒绝 PIP（拒绝可能被以"严重违纪"开除）
  - 要求 PIP 的具体标准、培训内容、考核方式
  - 保留所有 PIP 相关沟通记录
  - 三重举证责任：考核标准签字 + 培训/调岗记录 + 仍不胜任考核（北京三中院 (2025)京03民终16369 号宋某案）

## 五、证据清单——按场景分类

### A. 劳动关系证据

```
劳动合同（公司先盖，你再签，自己留一份）
社保缴费记录（支付宝/微信城市服务可查）
个人所得税缴交记录（个人所得税APP可查）
工牌、工作照（随手拍）
入职/任免文件
```

### B. 劳动报酬证据

```
工资条或工资详情表
报销单、出差补助单（拍照留存）
银行工资流水（银行APP可导）
个人所得税APP记录
```

### C. 解除劳动关系证据

```
离职申请表（主动辞职）——不要轻易签
离职通知书（被辞退）——不签字≠不接受
离职证明
非本人意愿离职通知书（EMS邮寄）
工作/财物交接证明
```

### D. 加班证据

```
加班安排邮件/群聊截图
钉钉/企业微信打卡截图
加班时报销的拍照记录
领导安排工作的聊天记录
```

### E. 公司经营困境证据（可提前预判）

```
企查查/天眼查合同纠纷记录
裁判文书网判决书
企查查开庭公告
```

### F. 程序违规证据（新增强相关）

```
门禁被取消的截图/照片
工作群被移出的截图
电脑被断网的照片
工位被撤的照片
公司拒绝出具解除证明的沟通记录
未通知工会的证据
```

## 七、劳动仲裁申请书填写规范

### 第一部分：请求事项（最重要）

- 写具体金额即可，**不要写计算过程**
- **尽可能完善**：提交后过了举证期就**不能变更请求**了
- 必须包括：工资差额、加班费、差旅费、经济补偿金、未休年假工资等，能想到的都要写

### 第二部分：叙述事实

- 写清楚：入职时间、月工资、合同签订情况、工资发放形式、离职原因
- 离职原因要按事实：是个人原因 / 被辞退 / 因拖欠工资被迫离职

### 第三部分：逐条解释请求

- 每条诉求说明：依据哪条法律、证据是什么、金额怎么计算

### 提交材料清单

```
1. 劳动人事争议仲裁申请书（按上面格式填写）
2. 身份证复印件
3. 证据复印件（份数：被申请人数量 + 1）
4. 证据目录清单
```

详细模板见 `templates/arbitration-application.md`。

## 八、N、N+1、2N 到底选哪个？

| 情况 | 公司应支付 | 适用场景 |
|------|-----------|---------|
| 合法解除（无过错） | N 或 N+1 | 协商一致 / 客观情况重大变化 |
| 违法解除 | **2N** | 公司无法证明解除合法 |
| 拖欠工资被迫解除 | **工资损失 + N** | 公司违法在先 |
| 恢复劳动关系 | **工资损失（持续计算）** | 你主动要求恢复 + 合同能继续履行 |
| **2025 年新规**：公司让签放弃社保协议 | **协议无效 + N** | 解释二第 19 条 |
| **2025 年新规**：违法解除后工资损失 | **按"正常劳动工资"标准** | 解释二第 18 条 |

### N 的计算（注意上限）

- N = 在职年限 × 月均工资（解除前 12 个月平均工资，含奖金/补贴）
- 月工资 > 当地社平工资 3 倍 → N 有上限（≤12 年，即封顶≤12 个月）
- 低于社平工资 3 倍的 → 无上限

### 录音在协商中的使用

- 协商录音必须**告知对方**（否则可能被认定非法取证）
- 录音中要体现：时间、地点、对方身份、具体事实
- 录音质量要好，能听清关键内容

## 九、心态建设（被低估的关键）

**最常见的放弃时机：**
- 被 HR 约谈后，被威胁套路吓到
- 仲裁立案后，觉得太麻烦放弃
- 调解阶段被公司给点小钱就接受

**必须做好的心理建设：**

1. **不要抱有任何幻想**——走到仲裁就是撕破脸了
2. **坚定信念，不要轻敌**——很多劳动者还没迈开步子就放弃了
3. **拖时间对你有利**——公司要花精力应诉，公司更急着解决
4. **仲裁期间不要撤诉**——没拿到钱就撤 = 前功尽弃
5. **不要被口头承诺骗了**——对方拖延时间的手段

## 十、2025-2026 年最新维权武器（重要补充）

### 新武器 1：解释（二）第 19 条 — 社保免责约定无效

> 用人单位与劳动者约定或者劳动者向用人单位承诺无需缴纳社会保险费的，人民法院应当认定该约定或者承诺无效。

**应用**：如果你签过"自愿放弃社保"协议 → 协议无效 → 你仍可主张：
- 要求公司补缴社保
- 据此解除劳动合同 + 主张经济补偿 N
- 主张因未缴社保导致的损失（如医疗费、生育津贴、失业保险金等）

### 新武器 2：解释（二）第 13 条 — 竞业限制条款生效条件

> 劳动者未知悉、接触用人单位的商业秘密和与知识产权相关的保密事项，劳动者请求确认竞业限制条款不生效的，人民法院依法予以支持。

**应用**：如果你不是高管/高级技术人员，且工作中未接触核心商业秘密 → 主张竞业限制条款对你不生效 → 不受违约金约束。

### 新武器 3：解释（二）第 18 条 — 工资损失计算标准

> 用人单位应当按照劳动者提供正常劳动时的工资标准向劳动者支付上述期间的工资。

**应用**：违法解除后选择恢复劳动关系 → 等待期间的工资损失按原工资标准算（不是最低工资），对高管尤其有利。

### 新武器 4：2026 年杭州中院 AI 替岗案

> 用人单位以 AI 的成本优势为理由，主动解除劳动关系，该理由不满足"劳动合同无法履行"的法定条件。

**应用**：公司以"AI 替代你的岗位"为由解除 → 主张违法解除 + 2N。
